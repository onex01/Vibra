# Паспорта железа

Здесь лежит описание того, **что физически стоит** в тестовых машинах. Это
не отчёт о поддержке Vibra: результат прогонов ядра живёт в
[../verified-hardware.md](../verified-hardware.md).

Разделение важно. «Linux видит EHCI на портах 1–3» — это свойство машины.
«Vibra не видит флешку» — это дефект драйвера. Смешивать их в одном файле
значит через месяц снова гадать, что именно было проверено.

## Зачем

Vibra видит только то, что умеет её собственный драйвер. Когда флешка не
появляется, `diag usb` показывает 15 пустых портов — и дальше начинаются
догадки: не тот контроллер, не тот режим, не тот transfer. Linux на той же
машине отвечает точно:

- к какому хосту подключено устройство (`ehci-pci` или `xhci_hcd`);
- какая скорость и версия USB у каждого устройства;
- есть ли у EHCI 64-битная адресация (`HCCPARAMS[0]`) — от этого зависит
  раскладка QH/qTD;
- в каком режиме SATA (AHCI или RAID) и поднялся ли линк;
- какие порты отданы companion-контроллеру (`PORTSC.OWNER`);
- Secure Boot, NX, MTRR, состояние прошивки.

Один такой прогон заменяет несколько итераций «пересобрал — не работает —
непонятно почему».

## Как снять

На тестируемой машине, с обычного Linux (live USB подходит), из корня
репозитория:

```sh
./scripts/hw-probe.sh
```

Скрипт сам запросит sudo. Результат:

```text
hw-probe-<производитель>-<модель>-<дата>/
hw-probe-<производитель>-<модель>-<дата>.tar.gz
```

Пришлите `.tar.gz` — этого достаточно.

Параметры:

| Флаг | Действие |
|---|---|
| `-o <каталог>` | явный путь отчёта |
| `--no-raw` | только `SUMMARY.md` |
| `--no-sudo` | без root: часть данных будет пустой |
| `-h` | справка |

### Что нужно для полного отчёта

Скрипт только читает: он не пишет в регистры, не меняет прошивку и не
трогает диски.

- **MMIO-регистры EHCI/xHCI.** Ядро с `CONFIG_IO_STRICT_DEVMEM=y` (Fedora,
  Ubuntu, Debian) закрывает `/dev/mem` для ресурсов, занятых драйвером.
  Загрузитесь с параметром `iomem=relaxed`: в GRUB нажмите `e`, допишите
  в строку, начинающуюся с `linux`, и нажмите F10. Для live USB это разово.
  Без него в `SUMMARY.md` будет честное «MMIO не читается» и список портов
  придётся смотреть по `lsusb -t`.
- **dmidecode** — модель, BIOS, память. Без root берётся из `/sys/class/dmi/id`.
- **smartctl** (`smartmontools`) — модели дисков и здоровье.
- **acpidump** (`acpica-tools`) — бинарные ACPI-таблицы. Без него скрипт
  всё равно копирует FADT/MADT/MCFG/HPET/DSDT из `/sys/firmware/acpi/tables`.

Отсутствие утилиты не ломает прогон: раздел помечается в разделе
«Что не удалось снять».

### Что редактируется

Перед упаковкой скрипт вырезает из текстовых логов: серийные номера, UUID,
Asset Tag, MAC-адреса и имя хоста. Бинарные ACPI-таблицы не трогаются —
серийников там нет, но при публикации проверьте их содержимое глазами.

## Что смотреть в отчёте

Порядок разбора, когда что-то не работает:

1. **`## USB-контроллеры`** — сколько EHCI/xHCI/UHCI и какой драйвер Linux
   их обслуживает. Если USB2-устройства висят на `ehci-pci`, а в Vibra
   драйвера EHCI нет — вопрос закрыт, это и есть причина.
2. **`### Регистры`** — `HCCPARAMS ... 64bit=YES` и `port N: ... CCS/PED/PP/
   OWNER`. `OWNER=companion` означает, что порт отдан компаньону, и порты
   самого EHCI его не увидят.
3. **`### Дерево (lsusb -t)`** — реальная скорость каждого устройства
   (12 / 480 / 5000 Мбит/с). Флешка на 480 Мбит/с в порту xHCI — это USB2,
   а не SuperSpeed.
4. **`## Контроллеры хранения`** и `Линки SATA` — режим AHCI/RAID и
   `SATA link up`. Если линка нет, диск не появится ни в одной ОС.
5. **`## Накопители`** — `Лог. сектор 512/4096` отвечает на вопросы про 4Kn.

## Файлы

- `README.md` — этот документ.
- `matrix.md` — сводная таблица по всем машинам.
- `hw-probe-<...>/` — отчёты (кладутся в репозиторий только по решению
  владельца; по умолчанию скрипт пишет в текущий каталог).

## Как добавить машину

1. Прогнать `./scripts/hw-probe.sh` на этой машине.
2. Добавить строку в `matrix.md` по данным `SUMMARY.md`.
3. Добавить запись в `../verified-hardware.md` — только после реального
   прогона Vibra на этой машине, с результатом и датой.
