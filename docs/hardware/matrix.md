# Матрица тестовых машин

Сводка того, что стоит в машинах, на которых проверяется Vibra. Источник —
`scripts/hw-probe.sh` (Linux), а не прогоны ядра. Статус Vibra — отдельная
колонка и отдельный файл [../verified-hardware.md](../verified-hardware.md).

Обновляется вручную по данным `SUMMARY.md` каждого отчёта.

## Что какая машина проверяет

Разные машины закрывают разные «слепые зоны». Это и есть причина держать
несколько, а не одну.

| Машина | Незаменима для |
|---|---|
| ThinkPad T450 | EHCI-only порты (USB2 на Haswell/Broadwell), MTRR, заблокированные прошивкой, отсутствие COM1, NX выключен в BIOS |
| Atermiter X99 D4 | NVMe, AHCI с 4Kn-дисками (512e), два EHCI рядом с xHCI |
| Мини-ПК i5-8350U | Kabylake/UHD 620, компактная прошивка, вероятно `i219` |
| Плата FM2 | legacy BIOS (CSM), AMD-чипсет, UHCI/OHCI-компаньоны, IDE-режим |
| Основной ПК | целевая производительность, дискретная графика |
| Ноутбук (старый) | legacy BIOS, IDE/PATA, USB 1.1 |

## Известные особенности, найденные заранее

Записаны, чтобы не выяснять заново.

| Машина | Особенность | Следствие |
|---|---|---|
| T450 | MTRR заблокированы прошивкой (`LOCK=1`) | `wrmsr` в MTRR даёт `#GP`; WC не включить, скорость решается уменьшением перерисовок |
| T450 | NX выключен в BIOS (`CPUID.80000001H:EDX[20]=0`) | ядро не пишет `EFER.NXE`; W^X деградирует |
| T450 | USB2-порты у EHCI, у xHCI все порты `PORTSC=0x2a0` | без драйвера EHCI флешка не видна ни в одном порту |
| T450 | SATA `DET=0` на всех портах | вероятно `SATA mode: RAID`; встроенный диск не виден AHCI-драйверу |
| T450 | COM1 отсутствует | только framebuffer и `/VIBRA.LOG` |
| X99 D4 | диски отдают 512 логических / 4096 физических | 512e, не 4Kn: проверка 4Kn на этой машине не пройдёт |

## Как пополнить

```sh
./scripts/hw-probe.sh                  # на тестируемой машине
```

Затем:

1. Строка в таблицу «Машины» по `SUMMARY.md`.
2. Строка в «Что какая машина проверяет», если машина закрывает новую зону.
3. Строка в «Известные особенности» для всего, что удивило.
4. После реального прогона Vibra — запись в `../verified-hardware.md`.

Правило: в «Машины» попадает только измеренное. Если поле не снимали —
оставьте пустым, а не пишите «вероятно».
